# SCADA-Edge-AI-Security
Project Overview: "A Python-based Modbus TCP SCADA simulation demonstrating False Data Injection Attacks (FDIA)."

Architecture: "Built with PyModbus. Simulates a PLC server and a SCADA client on localhost."

Vulnerability: "Demonstrates how Function Code 5 (Write Coil) can bypass unauthenticated Modbus networks to manipulate critical infrastructure."
